# Research & Thesis

My Master's program includes a research component exploring contemporary topics in data engineering and distributed systems. Here's what I'm working on.

---

## Current Research Direction

### Thesis Topic: "Data Pipeline Optimization in Distributed Cloud Environments"

**Focus Areas:**
- Cost-effective data processing at scale
- Real-time vs batch processing trade-offs
- Data quality in distributed systems
- Cloud-native architecture patterns

**Research Questions:**
1. How can we optimize data pipelines for cost without sacrificing performance?
2. What architectural patterns enable reliable data processing across multiple cloud providers?
3. How do we ensure data quality in real-time streaming pipelines?
